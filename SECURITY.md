# Security Policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** (Security → Advisories). You will get an acknowledgement within 7 days.

Particularly relevant: anything that lets one organization read or change another's data, bypasses role checks, reuses or forges tokens, or exposes secrets in logs or error responses.

Before deploying this starter, read the [Limitations](README.md#limitations) section: rate limiting, e-mail verification and password reset are not included.
